# Drift

A clickable prototype of a consent-based wellbeing check-in app: gentle nudges, a trusted circle, and one-tap crisis resources (988 Suicide & Crisis Lifeline).

All people and data in the demo are fictional mock data. Nothing is stored or sent anywhere. This is a design demo, not a medical or crisis service. If you are in crisis, call or text 988 (US).

Single static file: `index.html`.
